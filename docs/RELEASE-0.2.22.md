# 0.2.22

- 翻译设置重做为四个平级分页，统一表单布局，固定保存按钮。
- 内置 10,018 个 Wikidata 专业概念，去重后默认 10,041 条，保留词库导入/导出和自定义优先级。
- 同步此前的本机 Silero VAD、4 秒临时字幕预览和轻量术语语境能力。
- 安卓伴侣保持 0.3.2，本次无需更新手机。

Translation settings now use four consistent tabs with a fixed Save action. The app includes an offline Wikidata glossary (10,018 concepts; 10,041 default merged entries), custom import/export and verified local-update fallback. This public snapshot also includes the existing local Silero VAD and lightweight terminology context features. Android remains 0.3.2.

Whisper recognition weights still download separately. The Mac package is ad-hoc signed and not Apple-notarized. No personal keys, settings, pairing credentials or recordings are included.
