# Security / 安全

Report vulnerabilities through this repository's private security reporting feature if available. Otherwise open an issue containing only a short, non-sensitive description and request a private contact method before sending details.

Do not post API keys, complete pairing links, Bluetooth credentials, real meeting transcripts, personal recordings, or signing material in public issues.

API keys belong in the macOS Keychain through the app settings. Test examples must use fake credentials. Wi-Fi captions use local HTTP, so use a trusted network and protect pairing links.

发现安全问题时，优先使用仓库的私密漏洞报告入口。如该入口不可用，先提交不含细节的简短 Issue，请求私下沟通方式。请勿公开真实密钥、配对链接、设备凭据或会议内容。
