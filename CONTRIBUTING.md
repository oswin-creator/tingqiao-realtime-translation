# Contributing / 参与开发

Small, focused contributions are welcome.

1. Describe observed behaviour and expected results.
2. Use synthetic speech or text to reproduce a problem.
3. Build the affected target and run zsh test.sh for shared Mac or protocol changes.
4. Keep audio capture, recognition, translation, and phone transport changes focused.
5. Include system versions and selected engine. Remove personal content, credentials, device identifiers, and pairing information from screenshots and logs.
6. Preserve third-party notices and backwards-compatible settings and transcript decoding.

The Android app is the caption companion. A protocol change should be tested on both sides, including older snapshots.

欢迎提交范围明确的修复。描述复现步骤、预期表现与系统版本，测试优先使用合成语音和示例文字。涉及协议时请同时检查 Mac 与安卓实现，保留旧设置和记录的读取能力。提交前清理个人内容和密钥。
